# 蜘蛛纸牌专业版 (Spider Solitaire Pro)

一款基于 React 和 TypeScript 开发的高性能、现代化蜘蛛纸牌网页游戏。采用极简设计风格，配合丝滑的物理动效与专业级的博弈交互逻辑。

## 🌟 核心特性

- **极致流畅的交互**：
  - **真·整叠随动**：支持抓起一整叠合法序列进行平滑移动，手感极其跟手。
  - **60FPS 物理引擎**：基于 `Framer Motion` 的高性能渲染，移动、发牌、撤销均带有细腻的物理回弹感。
  - **3D 翻牌动效**：真实的 180 度翻牌仪式感，带深度投影反馈。
- **智能化游戏逻辑**：
  - **半结构化发牌算法**：采用“逆向工程”生成牌堆，大幅增加初始局面的连通性，从根源上降低死局概率。
  - **智能提示系统**：金色光晕高亮当前最佳移动路径，优先推荐同花色组合。
  - **非法移动反馈**：尝试非法操作时触发红色阴影与抖动效果，直观指引。
- **专业级视觉设计**：
  - **极简现代派牌面**：中心实心大花色水印，四角紧凑型镜像点数，完美复刻高级扑克牌质感。
  - **磨砂玻璃 UI**：顶部状态栏与胜利面板采用 Backdrop Blur 效果，视觉高级。
  - **紧凑型叠放布局**：优化纵向间距，支持在大屏幕与小屏幕上均能完美显示。
- **功能完备**：
  - **三档难度选择**：支持单色（简单）、双色（中等）、四色（困难）模式。
  - **无限撤销 (Undo)**：支持回溯最近 50 步操作。
  - **实时统计**：实时追踪步数、时长及回收进度。
  - **胜利勋章**：通关后展示详尽的最终成绩统计面板。

## 🛠️ 技术栈

- **前端框架**: React 18
- **语言**: TypeScript
- **动画引擎**: Framer Motion
- **图标库**: Lucide React
- **构建工具**: Vite
- **样式**: Vanilla CSS (CSS Variables)

## 🚀 快速开始

### 1. 环境准备
确保您的计算机上已安装 [Node.js](https://nodejs.org/) (建议 v16 或更高版本)。

### 2. 安装依赖
在项目根目录下执行：
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run dev
```
启动后，在浏览器中访问终端显示的本地地址（通常是 `http://localhost:5173`）。

### 4. 项目构建 (生产环境)
```bash
npm run build
```

## 🎮 操作指南

- **选中/移动**：单击一张可移动的牌将其选中（金色边框），随后点击目标位置进行移动。
- **取消选择**：在屏幕任何位置**双击**即可清空当前选中状态。
- **整叠拖拽**：直接长按并拖动一组牌，它们会自动作为一个整体随鼠标移动。
- **发牌**：当无法移动时，点击右下角的发牌堆（需保证每列都有牌）。
- **撤销**：点击顶部的旋转箭头图标回溯上一步。
- **提示**：点击金色的问号图标获取智能建议。
